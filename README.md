# 🩺 AI-Assisted Telemedicine Kiosk

A smart AI-driven kiosk system to assist patients with preliminary health checkups using computer vision and voice-based interfaces. Built for low-resource clinics and remote healthcare scenarios.

## 🧠 Project Overview

This kiosk leverages real-time image analysis, symptom classification, and voice interaction to guide users through a preliminary diagnosis process. It is especially useful in rural areas where direct access to doctors may be limited.

## 🚀 Features

- **Real-time Face & Object Detection** using YOLOv8 and OpenCV.
- **Symptom Classification** using a custom-trained CNN.
- **Voice-Based Interaction** using `pyttsx3` for text-to-speech guidance.
- **GUI Interface** built with Tkinter for seamless user experience.
- **Remote Monitoring Ready** – outputs can be sent to a doctor’s dashboard or database.

## 🛠️ Tech Stack

- `Python`, `OpenCV`, `TensorFlow`, `Keras`
- `YOLOv8` for detection
- `CNN` for symptom classification
- `pyttsx3` for TTS
- `Tkinter` for GUI

## 📊 Results

- Achieved **87%+ accuracy** in visual symptom classification.
- Real-time processing with minimal lag on mid-range hardware.
